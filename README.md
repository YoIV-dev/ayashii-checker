# Ayashii Checker（あやしいチェッカー）

**ネットで見つけたアプリや文章に、悪いしかけがないかを調べるサイトです。**

👉 **[https://yoiv-dev.github.io/ayashii-checker/](https://yoiv-dev.github.io/ayashii-checker/)**

無料です。インストールも会員登録もいりません。ブラウザで開くだけで使えます。

---

## なぜこのサイトが必要なのか

**だれでもアプリを作って配れる時代になりました。**
AIの力を借りれば、プログラミングを学んだことがない人でもアプリを作れます。便利なアプリがたくさん生まれる一方で、中身をだれもチェックしていないアプリも増えています。悪意のある人が、便利なツールのふりをしてパスワードを盗むプログラムを配ることもあります。

**AIは、読んだ文章にだまされることがあります。**
AIにWebページやメール、資料を読ませると、その中に隠された「命令」にAIが従ってしまうことがあります。これを「プロンプトインジェクション」と呼びます。人の目には見えない文字で書かれていることも多く、読んだだけでは気づけません。AIが自分でファイルを操作したりメールを送ったりできるようになった今、だまされたときの被害は大きくなっています。

**でも、中身を確かめるのはむずかしい。**
プログラムを読んで危険かどうか判断するには、専門知識が必要です。ウイルス対策ソフトは、こうしたスクリプトや文章に隠された命令までは見てくれないことがあります。

**そこで、「使う前に、ひと目で確かめられる」場所を作りました。**
ファイルや文章を入れるだけで、よく知られた危ない手口が入っていないかを調べ、何が危ないのかを分かる言葉で説明します。専門家でなくても、「これは使わないでおこう」と判断するきっかけになることを目指しています。

## こんなときに使えます

- ネットで見つけた個人のアプリを、**使う前に**大丈夫か確かめたい
- 「このコマンドをコピーして実行してください」と言われたけれど、何が起きるのか不安
- ChatGPT や Claude などのAIに文章やWebページを読ませる前に、**AIをだます隠しメッセージ**が入っていないか確かめたい

## 使い方

1. **[サイト](https://yoiv-dev.github.io/ayashii-checker/)を開きます。**
2. **調べたいものを入れます。**
   - アプリのファイルは、画面の枠の中にドラッグして入れます。ZIPファイルも、展開しないでそのまま入れられます。
   - 文章やコマンドは、「テキストを貼り付け」タブに貼り付けて「判定する」を押します。
3. **結果を見ます。** 4段階で表示されます。

| 結果 | どうすればいい？ |
| --- | --- |
| 🔴 危険 | 使わないでください。AIにも読ませないでください。 |
| 🟠 要注意 | 気になる点があります。理由を読んで、作った人や配っている場所が信頼できるか確かめてください。 |
| ⚪ 軽微な注意点のみ | 大きな問題は見つかりませんでした。気になる点だけ確認してください。 |
| 🟢 問題は見つかりませんでした | よく知られた危ないパターンは見つかりませんでした。 |

見つかった場所ごとに「何が危ないのか」が説明されます。目に見えない文字で隠されていた文章も、読める形にして表示します。

まず試してみたいときは、[サイト](https://yoiv-dev.github.io/ayashii-checker/)の「テキストを貼り付け」タブで「サンプルで試す」を選んでください。

## 調べたものが外に出ることはありません

- 入れたファイルや文章は、**あなたのパソコン（またはスマホ）の中だけで**調べます。インターネットには送りません。
- このサイトは、そもそも外部と通信できないように設定してあります。
- 何も保存しません。ページを閉じると、入れた内容も結果も消えます。「クリア」ボタンですぐ消すこともできます。

このサイトの中身はすべて[このページ（GitHub）](https://github.com/YoIV-dev/ayashii-checker)で公開しているので、だれでも確かめられます。調べ方のルールは [scanner.js](scanner.js) にまとめてあります。

## どんなものを見つけられるか

**AIをだます隠しメッセージ**
- 「前の指示は無視して」「ユーザーには言わないで」など、AIを思いどおりに動かそうとする文
- 文字を白くしたり、画面に表示されない場所に書いたりして、人には見えないようにした文
- パスワードや大事な情報をどこかへ送らせようとする文

**目に見えない文字**
- 画面には何も映らないのに、AIには読めてしまう文字
- 見た目と中身が食い違うように細工された文字
- 英語のアルファベットにそっくりな別の文字（なりすましに使われます）

**パソコンに悪さをするプログラム**
- ブラウザに保存したパスワードや、ログイン情報を盗み出すもの
- 盗んだ情報を、チャットアプリなどを使ってこっそり外部へ送るもの
- 他人があなたのパソコンを遠隔操作できるようにするもの
- パソコンの中のファイルを全部消してしまうもの
- パソコンを起動するたびに勝手に動くように仕込むもの
- パソコンの力を勝手に使って仮想通貨を稼ぐもの
- 中身を読めないように、わざとぐちゃぐちゃにしてあるもの

**入れただけで動き出すしかけ**
- インストールしただけで、勝手にプログラムが動くもの
- 有名なソフトの名前を一文字だけ変えた、ニセモノの部品（例: `lodash` → `lodahs`）
- フォルダを開いただけで動き出す設定
- AIアシスタントに「何でも確認なしで実行してよい」と許可する設定

## 気をつけてほしいこと

- **「問題は見つかりませんでした」でも、100%安全とは限りません。** よく知られた手口を探す仕組みなので、新しい手口や巧妙なものは見逃すことがあります。
- **ふつうのアプリでも「要注意」になることがあります。** 表示される理由を読んで判断してください。
- **迷ったら使わない**のがいちばん安全です。

## よくある質問

**Q. お金はかかりますか？**
かかりません。広告もありません。

**Q. スマホでも使えますか？**
使えます。ファイルを選ぶか、文章を貼り付けてください。

**Q. 大きなファイルも調べられますか？**
1つ3MBまでのファイルを調べます。写真や動画は調べません。

**Q. 判定がおかしいと思ったら？**
[こちら（Issues）](https://github.com/YoIV-dev/ayashii-checker/issues)から教えてください。GitHubのアカウントが必要です。報告するときは、パスワードや個人情報を書かないでください。
