# Ayashii Checker

**ネットで見つけたアプリや、AIに読ませる文章が「あやしくないか」をチェックするWebツールです。**

👉 **https://yoshiaki-git.github.io/ayashii-checker/**

インストール不要・登録不要・無料で、ブラウザで開くだけで使えます。

---

## こんなときに

- GitHub や SNS で見つけた個人製作のアプリを、**実行する前に**中身を確かめたい
- 「このコマンドを貼り付けて実行してください」と言われたが、何をするものか不安
- Webページや資料を ChatGPT・Claude などのAIに読ませる前に、**AIを操る隠し命令（プロンプトインジェクション）** が仕込まれていないか見たい
- コードの中に、画面に表示されない文字が紛れていないか調べたい

## 使い方

1. [サイト](https://yoshiaki-git.github.io/ayashii-checker/)を開きます。
2. 調べたいものを入れます。
   - **アプリ・プログラム**: ファイル、フォルダ、ZIP をドロップします。GitHub なら「Code → Download ZIP」で落としたZIPを、展開せずにそのまま入れられます。
   - **文章・コマンド**: 「テキストを貼り付け」タブに貼り付けて「判定する」を押します。
3. 結果が4段階で表示されます。

| 判定 | 意味 |
| --- | --- |
| 🔴 危険 | 悪意のあるコードや隠し命令の可能性が高いです。実行したり、AIに読ませたりしないでください。 |
| 🟠 要注意 | 注意が必要な箇所があります。理由を読み、配布元が信頼できるか確かめてください。 |
| ⚪ 軽微な注意点のみ | 大きな問題は見つかっていませんが、念のため確認したい箇所があります。 |
| 🟢 問題は見つかりませんでした | 既知の危険パターンは見つかりませんでした（安全の保証ではありません）。 |

見つかった箇所ごとに「何が問題か」「何行目か」が表示されます。見えない文字に隠されていた文章は、読める形に戻して表示します。

試しに使ってみたいときは、「テキストを貼り付け」タブの **サンプル** を選んでください。

## プライバシー

調べたファイルや文章は、**どこにも送信されず、保存もされません。**

- 解析はすべて、あなたのブラウザの中だけで行います。サーバーにはアップロードしません。
- ページ自体が外部と通信できない設定になっています（Content Security Policy で通信を禁止）。
- 入力内容と結果はブラウザに保存しません。ページを閉じたり移動したりすると消えます。「クリア」ボタンですぐに消すこともできます。

仕組みはすべてこのリポジトリで公開しているので、誰でも確かめられます。

## 何をチェックするか

**AIへの隠し命令（プロンプトインジェクション）**
- 「以前の指示を無視して」「ユーザーには伝えないで」のような、AIを乗っ取ろうとする文（日本語・英語）
- HTMLのコメントや、文字色を白にするなどして人間には見えなくした場所に書かれた命令
- パスワードやAPIキーを外部に送らせようとする指示

**見えない文字**
- 画面に表示されないのにAIには読める文字（タグ文字・ゼロ幅文字）
- コードの見た目と中身を食い違わせる制御文字
- 英字にそっくりな別の文字（ロシア語の「а」など）

**危険なプログラム**
- ブラウザに保存したパスワードや Cookie、SSH鍵、仮想通貨ウォレットを盗み出す処理
- Discord や Telegram など、盗んだ情報の送り先によく使われる場所への送信
- PCを外部から操作できるようにするコード（リバースシェル）、ファイルを全部消すコマンド
- 起動時に自動で動くように登録する処理、PCで勝手に仮想通貨を採掘する処理
- 中身を読めなくする加工（難読化）や、ネットから取ってきたコードをその場で実行する処理
- ネット上のスクリプトを確認せず実行する `curl ... | sh`

**インストールするだけで動く仕掛け**
- `npm install` だけで実行されるスクリプト
- 有名なパッケージに一文字違いで似せた偽物（例: `lodash` ではなく `lodahs`）
- VS Code でフォルダを開いただけでコマンドが走る設定
- Claude Code などのAIエージェントに、全コマンドを無確認で許可する設定

ほかにも、コード内に書かれたままのAPIキーや、ダブルクリックで実行される形式のファイル、コンパイル済みの実行ファイルの存在を知らせます。

## 注意してほしいこと

- **「問題は見つかりませんでした」は安全の保証ではありません。** 決まったパターンを探す仕組みなので、巧妙なマルウェアは見逃すことがあります。
- **正常なアプリでも検出されることがあります。** たとえば開発ツールがコマンドを実行するのは普通のことです。表示される理由を読んで判断してください。
- コンパイル済みの実行ファイル（.exe など）の中身までは調べられません。
- 迷ったら **実行しない** のがいちばん安全です。どうしても試すなら、仮想マシンなど本番環境から切り離した場所で動かしてください。

## よくある質問

**Q. スマホでも使えますか？**
はい。ファイルの選択とテキストの貼り付けが使えます。フォルダのドロップはPCのブラウザ向けです。

**Q. 大きなリポジトリも調べられますか？**
3MBを超えるファイル、画像・動画、`node_modules` などの依存フォルダは、時間短縮のため初期設定でスキップします。依存フォルダはチェックボックスをオンにすると調べられます。

**Q. 誤検知や見逃しを見つけました。**
[Issues](https://github.com/Yoshiaki-git/ayashii-checker/issues) で教えてください。報告の際、本物のマルウェアや個人情報・APIキーをそのまま貼り付けるのは避けてください。

## 開発者向け

ビルド不要の静的サイトです。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。判定エンジンのテストは次のコマンドで動きます。

```bash
node test/run.js
```

| ファイル | 内容 |
| --- | --- |
| [scanner.js](scanner.js) | 判定エンジンとすべての検出ルール |
| [app.js](app.js) | 画面の処理（ファイル読み込み、ZIP展開、結果表示） |
| [samples.js](samples.js) | デモ用サンプル（すべて無害な文字列） |
| [vendor/jszip.min.js](vendor/jszip.min.js) | ZIP展開ライブラリ [JSZip](https://stuk.github.io/jszip/)（MIT License） |

ルールを追加・変更したら `node test/run.js` で確認してください。`index.html` から読み込むファイルにはキャッシュ対策のバージョン番号（`?v=2`）が付いているので、更新時は数字を上げてください。
